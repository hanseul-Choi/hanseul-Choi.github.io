## 개요

수작업으로 이뤄지던 혼잡도 보고를 자동화하기 위해, RTSP CCTV 기반 실시간 혼잡도 분석 웹 시스템을
설계·개발했습니다.

## 시스템 구조

- 48개 CCTV 영상과 바운딩박스를 WebRTC로 제공, 주요 12개 채널에는 사람 수 기반 혼잡도 분석·통계 적용
- FastAPI Backend 2개를 GPU별로 분리하고, 카메라·모델별 Nginx upstream 라우팅 구성
- Docker 이미지를 tar로 패키징해 폐쇄망 서버에 배포, PostgreSQL과 모델 파일은 볼륨으로 영속화
- RTSP 재접속, health check, restart policy, 로그, 개인정보 보호를 위한 영상 블러 처리 적용

## 성능 개선

- OpenCV 버퍼와 최신 프레임 유지 구조로 12채널 처리 지연을 0.5초에서 0.1초로 (약 80% 개선)
- 프레임 원본 테이블과 5분 통계 테이블을 분리하고 인덱스를 적용해, 1년·12개 카메라 조회 시간을
  약 10초에서 5초로 단축
