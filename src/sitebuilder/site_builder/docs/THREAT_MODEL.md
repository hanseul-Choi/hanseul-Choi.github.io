# THREAT_MODEL — site_builder

## 자산
- 로컬/CI 파일시스템 (빌드 출력 디렉터리 밖에 대한 쓰기 방지), 로컬 개발 서버의 네트워크 노출 범위

## 위협
1. **경로 순회로 임의 위치에 파일 쓰기**: `--output ../../etc`처럼 상위 디렉터리로 벗어나는
   출력 경로.
   - 대응: 출력 경로를 `resolve()` 후 저장소 루트 하위인지 검증, 아니면 즉시 실패.
   - 테스트: `test_pipeline.py::test_rejects_output_dir_outside_repo`.
2. **개발 서버의 의도치 않은 외부 노출**: `serve` 명령이 기본값으로 모든 인터페이스에 바인딩되어
   로컬 네트워크의 다른 기기에서 접근 가능해지는 경우.
   - 대응: 기본 바인딩은 `127.0.0.1`. `--host 0.0.0.0`은 명시적 opt-in.

## 신뢰 경계
- CLI 실행자는 저장소 소유자(신뢰됨)로 가정. CI 환경에서는 `--output`이 워크플로 파일에
  고정 상수로만 전달되고 외부 입력으로 대체되지 않는다.
