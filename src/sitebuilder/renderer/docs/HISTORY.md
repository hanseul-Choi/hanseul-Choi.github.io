## 2026-08-06 — `collapsible_h3` 필터 추가
- 프로젝트 상세 페이지의 "문제 및 해결" 같은 긴 `<h3>` 섹션을 네이티브 `<details>`/`<summary>`
  아코디언으로 감싸는 필터 추가 (BeautifulSoup으로 h3 + 다음 h2/h3 전까지의 형제 노드를 재배치).
  JS 없이 브라우저 기본 동작만으로 펼치기/접기 + 키보드 접근성 확보. `<h2>` 섹션(개요/성과 등)은
  건드리지 않음 — 이 프로젝트의 콘텐츠 구조상 `<h3>`는 문제 항목에만 쓰이기 때문에 헤딩 레벨만으로
  안전하게 범위를 구분할 수 있었음.

## 2026-08-06 — `lightbox_images` 필터 추가
- 구조도 이미지가 인라인 크기로는 잘 안 보인다는 피드백에 따라, 모든 `<img>`를 클릭하면 확대되는
  라이트박스로 감싸는 필터 추가. `:target` CSS 셀렉터 기반 순수 CSS 구현(JS 없음) — 이미지가
  `#lightbox-N` 앵커가 되고, 같은 id의 풀스크린 오버레이 링크가 열림/닫힘을 담당. `project_detail.html`
  에서만 사용 (`detail.body_html`), 프로젝트 카드 썸네일에는 적용 안 함 — 카드 이미지는 클릭하면
  상세 페이지로 이동하는 게 기존 동작이라 라이트박스를 얹으면 혼란스러울 수 있음.
